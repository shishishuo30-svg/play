双击 `index.html` 可运行本机双人游戏。长按未猜格约半秒插红旗，再次长按取消；游戏结束时双方飞机统一显形。

局域网联机：从项目根目录运行 `node web/server.js`，或双击根目录的 `启动联机.cmd`。两台设备连同一个 Wi-Fi，用浏览器打开终端显示的局域网地址，一人创建房间，另一人用 6 位房间号加入。保持服务端电脑和终端运行；首次运行允许 Node.js 通过专用网络防火墙。

在本目录运行 `node tests.js`、`node client-tests.js` 和 `node network-tests.js` 验证规则、交互及双端联机。详细说明见根目录 README.md。

不同 Wi-Fi / 远距离联机：将同一套服务部署到公网 HTTPS 域名，两人打开这个域名即可通过房间号加入；小程序配置相同服务地址后，也能加入同一个房间。部署步骤见 `../deploy/README.md`。
