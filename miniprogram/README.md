在微信开发者工具中导入此目录并编译。`project.config.json` 使用占位 AppID，需要运行者替换成自己的小程序 AppID。

支持单设备双人轮流对战：长按未猜格插红旗，再次长按取消，不消耗回合。飞机击毁后保持隐藏，游戏结束后全部显形，可切换双方空域复盘。

小程序现已支持创建房间、输入 6 位房间号加入、自动交换回合、断线重试、恢复房间和双方同意重开，可与网页版互相对战。

先按根目录 `deploy/README.md` 部署服务端，再在本目录 `config.js` 填入 HTTPS 服务地址，并在微信小程序后台添加 request 合法域名。所有玩家连接同一个公网服务后，即可跨 Wi-Fi 或使用移动数据远程对战。未配置服务端时仍可进行本机双人游戏。

本地开发时可临时配置电脑的局域网 HTTP 地址并关闭开发者工具域名校验；这不能替代正式版本要求的 HTTPS 和合法域名配置。项目默认 AppID 是占位值，真机发布需替换为自己的 AppID。
