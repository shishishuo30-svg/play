# 云空战棋：飞机部位猜击

目录内容：`web/` 为免安装网页游戏，`miniprogram/` 为原生微信小程序工程。

## 游戏规则

- 支持本机双人轮流对战、局域网对战及部署后的公网对战，网页版和小程序可以互相加入同一房间；P1 先手。每人自己的 12×12 地图各随机布置 3 架飞机。
- 每架飞机是 10 格的飞行器：中心机头 1 格、机身 3 格、双翼共 4 格、尾翼 2 格。飞机可朝上、下、左、右；三架不重叠且之间至少空一格，防止相邻飞机被当成同一架。
- 轮到谁，就在对方棋盘点一格。机头直接击毁整架飞机，只标记机头爆炸，机体保持隐藏；机身格子显示红色 ✓ 作为方向线索；空格变为空心。三种结果都消耗一次猜测并交换回合。击毁后尚未猜过的机身格仍可猜击。
- 长按未猜过的格子约半秒可标记小红旗，再次长按取消。红旗不消耗回合，只保留在自己的视角；有红旗的格子要先取消标记才能猜击。
- 游戏结束时双方全部飞机统一显形，可以点击“查看另一方空域”复盘。
- 先击毁对方全部三架飞机的人获胜。每轮先显示“交接屏”，再点“开始猜测”，不在交接页展示对方棋盘。

## 网页版

直接双击 `web/index.html` 即可游玩；保留整个目录结构即可运行，不依赖网络或第三方库。支持鼠标、触摸和窄屏。

### 同一 Wi-Fi 多设备联机

1. 在一台安装了 Node.js 18 或更新版本的电脑上，从本项目目录运行 `node web/server.js`（也可双击 `启动联机.cmd`）。
2. 保持终端运行。电脑和手机连接同一个 Wi-Fi，所有玩家在浏览器打开终端显示的 `http://局域网IP:3000` 地址。其他设备需要使用电脑的局域网 IP。
3. 一人点击“创建联机房间”，另一人输入显示的 6 位房间号并点击“加入房间”。每个房间支持两人，可创建多个独立房间。
4. P1 先手，每次猜击后自动同步并交换回合，无需交接设备。刷新原标签页可恢复房间；断网会提示并自动重试。
5. 点击“新对局”提出重开，另一人也点击后开始新一局。房间连续两小时无人访问会过期，服务关闭后房间不保留。

Windows 首次运行若提示防火墙，请允许 Node.js 在专用网络通信。如果手机无法访问，检查电脑防火墙、两端 Wi-Fi 及路由器是否开启了访客网络/设备隔离。可用 PowerShell 的 `$env:PORT=3001` 指定其他端口后启动服务。

联机布局、回合和胜负由服务端管理，游戏结束前不会向浏览器发送飞机坐标；红旗只在各自设备当前页面内保存，刷新后清空。局域网联机无需额外 npm 依赖。

## 微信小程序版

将 `miniprogram/` 目录导入微信开发者工具，使用自己的 AppID，编译并预览。本版支持长按插旗、取消、结束显形，以及创建/加入房间、自动同步、恢复房间、双方同意重开。单机无需服务端；联机需要在 `miniprogram/config.js` 填写服务端 HTTPS 地址，并在微信后台配置 request 合法域名。

### 不同 Wi-Fi、远距离联机

把同一套 Node.js 服务部署到公网 HTTPS 域名后，网页版打开这个域名，小程序连接同一个域名，两人输入房间号即可对战，距离和 Wi-Fi 不受限制。项目已提供 Dockerfile 和 HTTPS 代理示例。具体步骤见 [公网部署说明](deploy/README.md)。目前未实际部署公网服务，需要自行提供服务器、HTTPS 域名和小程序 AppID。

飞机形状（H 为机头，■ 为飞机其他部位，· 为空白；可以旋转）：

```text
··H··
■■■■■
··■··
·■■■·
```

猜击后先查看结果，再点击“交给 P2/P1”，交接后点击开始下一回合。命中也不连击，已揭示格子不能重复猜。

## 测试

运行 `node web/tests.js` 检查 120 个随机布局、命中、击毁隐藏和结束状态；运行 `node web/client-tests.js` 检查长按插旗/取消、防误触和短按猜击；运行 `node web/network-tests.js` 检查双端完整对局、回合校验、位置保密、状态同步、重新读取房间和双方重开。

运行 `node web/miniprogram-tests.js` 通过实际 HTTP 服务验证小程序页面的建房、加入、同步、红旗、隐藏布局、恢复房间、前后台切换、重开及退出。该测试模拟微信 API，不替代微信开发者工具和真机验证。
